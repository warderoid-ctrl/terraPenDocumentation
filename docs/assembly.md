# Fitting the toolhead

Your terraPen ships with the stepper toolhead **not attached**. Fitting it is the
first thing to do, and it is the only assembly required.

You will need the hex key supplied in the box.

## Steps

1. Unpack the toolhead and position it against its mounting on the carriage.
2. Fit the **four screws** supplied with it.
3. Tighten them evenly with the hex key — firm, but do not over-torque them.

That is the whole job. Once the toolhead is on, continue to
[First time setup](1sttimeuse.md).

!!! note "The stepper toolhead"
    The stepper gives roughly **14 mm** of Z travel. It is the default toolhead in
    [terraForge](terraForge.md), so you should not need to change any configuration
    to use it.

!!! tip "Do this before powering on"
    It is easier to work on the machine with no power connected and nothing able to
    move.
