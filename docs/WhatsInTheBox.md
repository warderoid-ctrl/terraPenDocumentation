# What's in the box

Check everything below is present before you start. If anything is missing, get in
touch on [Discord](https://discord.gg/fEXrmUm5nR).

| Item | Notes |
|---|---|
| terraPen plotter | 1x, with the toolhead already fitted |
| Power supply | 12 V 2 A universal adaptor (UK plug shown) |
| Pen | A pen to get you started — most pens will fit |
| Calibration plot | The test drawing made on your machine before it shipped |
| Pen height puck | 2 mm spacer for setting how far the pen sits off the paper |
| Corner tabs | For holding paper flat on the bed |
| Hex keys | 0.24 mm, 2.5 mm and 4 mm |
| SD card | Already installed, with sample files on it |

!!! note "Keep the calibration plot"
    Do not throw it away. You will plot onto the back of it in
    [Your first plot](1stPlot.md), and it is a useful reference for what your machine
    should be capable of.
